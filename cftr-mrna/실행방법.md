# 실행 방법 (윈도우)

## 1. 파이썬 확인

윈도우 키 → `cmd` 입력 → 엔터. 검은 창에서

```
python --version
```

숫자가 나오면 2번으로. 아무것도 안 나오거나 스토어가 열리면 python.org에서
설치. 설치 창의 **Add python.exe to PATH** 체크 필수.

## 2. 설치

이 폴더를 탐색기로 열고, 위쪽 주소 칸 클릭 → `cmd` 입력 → 엔터. 그 창에서

```
pip install -r code/requirements.txt
```

ViennaRNA에서 막히면 아래를 먼저 치고 위를 다시 실행.

```
pip install --only-binary :all: ViennaRNA
```

## 3. 실행

```
cd code
uvicorn api:app --port 8000
```

`Uvicorn running on http://127.0.0.1:8000` 이 뜨면 켜진 것. 이 창은 닫지 말 것.

## 4. 접속

브라우저 주소창에 `127.0.0.1:8000`

## 5. 종료

검은 창에서 Ctrl + C
